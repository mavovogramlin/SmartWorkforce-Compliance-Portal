# Smart Workforce Compliance & Automation Portal
## Overview
A hybrid enterprise solution combining ASP.NET Core MVC with Microsoft Power Platform to automate workforce requests, approvals, compliance tracking, and reporting.

## Technology Stack
- ASP.NET Core MVC (C#)
- SQL Server
- Entity Framework Core
- Power Automate
- Power Apps
- Power BI

## Key Features
- Role-based authentication and authorization
- Employee request management
- Supervisor approval workflows
- Automated notifications
- Analytics and compliance dashboards

## Architecture
This solution follows a hybrid architecture where the MVC application acts as the system of record, while Power Platform components enhance productivity and analytics.
